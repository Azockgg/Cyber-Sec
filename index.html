Hash identifizieren #

Ermittelt den Hash-Typ und gibt den passenden Hashcat-Modus (-m) aus.

Hash-Typ / Modus bestimmen
hashcat --identify hash.txt

Angriffsmodi -a #

Der Parameter -a legt die Angriffsart fest.

-a 0Straight — Wortlisten-Angriff
hashcat -a 0 hash.txt wortliste.txt
-a 1Combinator — zwei Wortlisten verknüpfen
hashcat -a 1 hash.txt links.txt rechts.txt
-a 3Brute-Force / Mask — Masken-Angriff
hashcat -a 3 hash.txt '?u?l?l?l?l?d?d'
hashcat -a 3 hash.txt '?1?1?1?1' -1 '?l?d' --increment
-a 6Hybrid Wordlist + Mask — Wort + angehängte Maske
hashcat -a 6 hash.txt wortliste.txt '?d?d?d?d'
-a 7Hybrid Mask + Wordlist — Maske + vorangestelltes Wort
hashcat -a 7 hash.txt '?d?d?d?d' wortliste.txt
-a 9Association — Hash mit Hinweis + Regeln
hashcat -a 9 hash.txt wortliste.txt -r rules/best64.rule

Masken-Parameter #

PlatzhalterZeichensatz
?lKleinbuchstaben abcdefghijklmnopqrstuvwxyz
?uGroßbuchstaben ABCDEFGHIJKLMNOPQRSTUVWXYZ
?dZiffern 0123456789
?sSonderzeichen !"#$%&'()*+,-./:;<=>?@[\]^_{|}~`
?aAlle druckbaren Zeichen (?l + ?u + ?d + ?s)
?bAlle möglichen Bytes 0x00 – 0xff
?hHexadezimal klein 0123456789abcdef
?HHexadezimal groß 0123456789ABCDEF
Custom-Charsets: Mit -1, -2, -3, -4 lassen sich eigene Zeichensätze definieren und als ?1–?4 in der Maske verwenden.

Erweiterte Befehle #

Regeln direkt im Combinator- bzw. Hybrid-Angriff auf einzelne Wörter anwenden.

Combinator mit Rules pro Seite (-j = links, -k = rechts)
hashcat -a 1 --stdout -j 'c$1' -k 'u$!' links.txt rechts.txt
Hybrid mit Custom-Charset + Increment 4–6
hashcat -a 6 -1 '$€!' star.hashcat jahre_staedte.txt '?1?1?1?1?1?1' --increment --increment-min 4 --increment-max 6

Regeln (Rules) #

Regel-Funktionen zur Wort-Manipulation — nutzbar mit -r datei.rule oder inline über -j/-k.

Groß-/Kleinschreibung (Case)

lalles klein
ualles groß
ccapitalize (erster Buchstabe groß)
Cinvert capitalize (erster klein, Rest groß)
ttoggle all (Groß/Klein umkehren)
TNtoggle an Position N

Nichts / Umkehren

:nichts tun
rWort umkehren (abc → cba)
dverdoppeln (abc → abcabc)
freflektieren (abc → abccba)

Anhängen / Voranstellen / Löschen

$XZeichen X anhängen
^XZeichen X voranstellen
[erstes Zeichen löschen
]letztes Zeichen löschen
DNZeichen an Position N löschen
xNMM Zeichen ab Position N ausschneiden

Einfügen / Überschreiben

iNXZeichen X an Position N einfügen
oNXZeichen an Position N mit X überschreiben

Rotieren / Verschieben / Duplizieren

{nach links rotieren
}nach rechts rotieren
pNWort N-mal duplizieren

Länge / Kürzen

'NWort nach N Zeichen abschneiden (truncate)

Ersetzen (Substitution)

sXYalle X durch Y ersetzen (z. B. sa@ → alle a werden @)
@Xalle Vorkommen von X löschen

Zeichen-basierte Manipulation (positionsweise)

zNerstes Zeichen N-mal duplizieren
ZNletztes Zeichen N-mal duplizieren
LNbitweise Shift links an Position N
RNbitweise Shift rechts an Position N
+NASCII-Wert an Position N erhöhen
-NASCII-Wert an Position N verringern

„Leet"-artige und weitere

kerste zwei Zeichen tauschen
Kletzte zwei Zeichen tauschen
*NMZeichen an Position N und M tauschen

Wörterlisten #

Listen kombinieren, erweitern, durchsuchen und filtern.

Zwei Listen der Reihe nach kombinieren
hashcat --stdout -a 1 liste1.txt liste2.txt > kombiniert.txt
Liste mit sich selbst kombinieren (-j links, -k rechts)
hashcat --stdout -a 1 -j l -k l list.txt list.txt > staedte.txt
Kombinieren mit Rules pro Seite
hashcat --stdout -a 1 -j 'c$1' -k 'u$!' links.txt rechts.txt > out.txt
Kombinieren + nach Mindestlänge filtern (≥ 8)
hashcat --stdout -a 1 wortliste.txt wortliste.txt | awk 'length >= 8' > out.txt

Durchsuchen / Filtern mit grep

Nach mehreren Wörtern filtern (-w ganzes Wort, -i Groß/Klein egal)
grep -E -w -i 'Haus|Maus' wortliste.txt > gefiltert.txt

John the Ripper #

Hashes aus Dateien extrahieren mit den *2john-Tools.

Dateityp herausfinden
file name.txt
Passendes *2john-Tool finden (Kali/Debian)
ls /usr/share/john/*2john*
… bei Jumbo-Quellinstallation
ls /path/to/john/run/*2john*
Hash aus ZIP-Datei extrahieren
zip2john Datei > out.txt
Für andere Dateitypen gibt es passende Varianten wie rar2john, pdf2john, office2john, ssh2john usw. Die extrahierte out.txt lässt sich anschließend mit John oder Hashcat knacken.
